# Touch Client - Instalación Rápida

## Instalación

1. **Hacer doble clic** en `Touch Client Setup 1.0.0.exe`
2. **Seguir** el asistente de instalación
3. **Esperar** a que la instalación se complete
4. **Ejecutar** Touch Client desde el menú Inicio

## Uso

- **Abrir** Touch Client desde el menú Inicio
- **La aplicación se ejecutará** automáticamente
- **No requiere Docker** ni configuración adicional

## Desinstalación

- **Panel de Control** → **Programas y características**
- **Buscar** "Touch Client"
- **Hacer clic** en "Desinstalar"

## Solución de Problemas

- **Si la instalación falla**: Ejecutar como administrador
- **Si la aplicación no inicia**: Reiniciar la computadora
- **Si hay problemas**: Contactar al administrador del sistema
